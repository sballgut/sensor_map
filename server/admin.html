준비된 패키지 배포

B·C가 제공한 map.json, graph.json, destinations.json, model.json 네 파일이 서버 PC의 폴더에 있어야 합니다. JSON 문법과 해시를 검사하며, 실제 보행 가능 여부·모델 품질은 검토자가 확인해야 합니다.
