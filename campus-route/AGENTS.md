# Campus Route 개발 지침

- 지도 및 경로 안내의 대상은 충북대학교 개신캠퍼스로 한정한다. 실제 지도 도입 시 캠퍼스 경계를 검증하고 다른 캠퍼스·캠퍼스 외부 경로를 포함하지 않는다.
- 현재 목표는 Android 단일 app 모듈의 오프라인 보행 앱이다. 기존 동작을 보존하고 단계별 확장한다.
- 가상 지도·위치·센서는 반드시 샘플/데모로 표시한다. 실측 없이 충북대학교 개신캠퍼스 실제 지도나 위치 정확도라고 주장하지 않는다.
- 2D 지도와 전체 화면 3D 내비게이션을 구분한다. 좌우 분할하지 않는다.
- 실제 3D 렌더링은 `rendering/`에 둔다. Canvas 원근 투영으로 대체하지 않는다.
- `domain/model`과 `routing`에 Android 의존성을 추가하지 않는다. 2D/3D/QR은 같은 Route를 사용한다.
- 로컬 좌표 단위는 미터, x 동쪽/y 북쪽, GL z=-y이다. 위경도를 직접 평균하지 않는다.
- A* 변경 시 최적성·비용·단절·방향 제한 테스트를 유지한다. 휴리스틱은 admissible이어야 한다.
- 변경 검증: `./gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug`.
- SDK/JDK/기기가 없어 수행하지 못한 검증은 구분해 보고한다. 빌드 성공을 기기 동작 검증으로 표현하지 않는다.
- 실제 GPS/BLE는 권한·수집 동의·보존/삭제 정책과 함께 도입한다. BLE 무수신이어도 GPS 안내는 가능해야 한다.
- 서버 저장 성공 ACK만 전송 완료로 인정한다. 임의 Mock ACK를 실제 서버 성공으로 표시하지 않는다.
- 팀별 책임과 인터페이스는 README 표를 따른다. 기능 구현과 함께 README 및 검증 기록을 갱신한다.

- 기본 지도는 gaesin_campus.json이다. OSM/SMASH-CBNU 데이터 출처와 ODbL 고지를 유지하고, SMASH 게임 코드·그림은 복사하지 않는다.
- 지도 배경·도로·2D/3D 건물은 밝은 무채색으로 유지한다. 파란색은 선택 경로·현재 위치 안내에 한정한다.
- 데이터 변경 시 tools/import_osm.py와 Python 경계/연결 테스트를 실행한다. 목적지는 검증된 출입구가 아니라 인근 OSM 보행 노드임을 표시한다.
