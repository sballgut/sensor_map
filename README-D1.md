# D-1 목적지 검색 UI 첫 구현

Android Studio에서 이 폴더 아래 **android** 폴더를 연다.

- 목적지 검색 → 선택 → 하단 상세창 → 취소.
- 지도는 D-2 연결 전 영역이며 실제 위치·경로는 표시하지 않는다.
- 시험용 목적지는 실제 좌표가 없는 예시 자료다.
- 기존 수집·설정은 오른쪽 위 버튼으로 연다.
- 자세한 데이터 계약과 검증 범위: [docs/D1_DESTINATION_UI.md](docs/D1_DESTINATION_UI.md).

기준: sballgut/sensor_map의 feature/ae-base, e74c3ee8bb608d74f570d076b095e880143a3579.
공유 브랜치: d1-ui. 별도 Kotlin 3D 앱과의 통합은 이번 단계에서 완료하지 않았다.
