## Campus Route 지도 앱

개신캠퍼스 오프라인 지도·A*·3D 보행 데모는 [`campus-route/`](campus-route/)에 있습니다. Android Studio에서 **campus-route 폴더 자체**를 열어 실행하세요. [실행 및 구조](campus-route/README.md), [검증 기록](campus-route/docs/VALIDATION.md).

기존 `android/`의 A/E 센서 앱과 `server/`는 유지합니다. Campus Route는 별도 앱이며 센서 수집·TeamBridge·서버 버전 배포와 아직 연결되지 않았습니다. 현재 위치는 시뮬레이션이고, 안내 경로의 현장 통행 및 건물 출입구는 검증 전입니다.
